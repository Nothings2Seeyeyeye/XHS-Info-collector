# AI 对话工作台

AI 页与素材库并列，参考 [腾讯 ima](https://ima.qq.com/) 的对话、知识库与历史入口，沿用拾页的本地存储和素材阅读界面。

## 开始使用

1. 在 **设置 → AI 对话模型 → 添加模型** 中填写显示名称、模型 ID、API Base URL 和 Key。支持兼容 Chat Completions 的服务，也支持本机免密模型。可添加多个模型并在对话中切换。
2. 按模型实际能力选择“模型支持图片理解”。Key 加密保存在本机，编辑时留空保留原 Key。连接测试仅发送一句问候，不发送素材。
3. 进入 **AI 对话**，输入 `@` 和关键词，用方向键与回车选择素材；也可点击“引用素材”按类型或文件夹筛选。图文和视频可以混合，每轮最多 8 份。
4. 选择模型并提问。支持流式回答、连续追问、停止生成、复制回答、Markdown 导出、历史搜索、重命名和删除对话。
5. 从素材库多选后点击“问 AI”，或在素材详情中点击“问 AI”，可直接带入新对话。回答引用和上下文素材卡片均可打开原素材。

连续追问默认保留上轮素材，可随时增删。切换到设置或素材库时，当前草稿和附件会保留。刷新后可重新打开已保存的对话；未发送草稿不保证跨刷新保留。

## 分析范围

- 提供所选素材的标题、作者、正文和已有 OCR 文字。不会自动上传整个素材库，也不会自动执行 OCR。
- 图片模型：每条图文均匀选取最多 6 张图片，包含首尾；全部附件每轮最多 24 张画面。本机缩小到最长边 1024 像素后发送。
- 视频：均匀抽取最多 6 帧并标注时间位置，结合原文分析。**第一版不转写音频、不上传完整视频，不能保证覆盖所有视频细节。**
- 文本模型：只发送原文与已有 OCR，不发送画面。
- 素材文字与近期对话有长度预算；截取情况会记录在素材的覆盖范围中。服务商的模型上下文、图片数量及额度限制仍然适用。
- 引用由模型生成，需要结合原文判断结论是否准确。第一版没有联网搜索、全库自动检索或向量索引。

## 存储与运行

- 新增 `ai_models`、`chat_threads`、`chat_messages` 表，启动自动创建，兼容原数据库。对话模型与 OCR 配置独立，Key 加密存储。
- 请求使用已有直连网络模块，不继承环境代理，不跟随携带 Key 的重定向。网页不会收到原始 Key 或模型服务原始错误响应。
- 后端独立生成，网页通过 SSE 接收已保存的回答。关闭或切换网页不会取消生成；主动停止保留部分内容。后台重启会标记未完成回答为停止，避免自动重发产生重复费用。
- 每会话同时只生成一个回答，整个服务最多两个；请求 ID 防止重试重复调用模型。异常、空响应和连接中断均进入可见终态。删除会话保留原素材。

## 验证

- Python 45 项检查通过，覆盖多附件、历史、图片与真实测试视频抽帧、权限、密钥、停止、重复请求、错误以及原有登录/采集流程。
- 前端 TypeScript 与构建通过。浏览器联调用独立临时数据库、合成图片和本机模拟模型，验证流式对话、引用回看、连续追问、刷新恢复及停止生成。
- 真实模型的回答质量与接口兼容性，需要填写模型配置后验证。
