# UI/UX 升级

本次在现有功能上统一为深墨导航、暖白内容区与克制的铜色点缀；放大页面标题、笔记正文及卡片信息，并使用本地打包的 Manrope 和 Cormorant Garamond 字体。

## 浏览与整理

- 素材库提供图库与列表两种视图，记住展示偏好。
- 标签筛选改为可搜索选择器，原始标签与个人标签分开查看。
- 搜索和筛选条件可见且可单独移除，保留加载反馈。
- Cmd/Ctrl+K 聚焦素材搜索；切换页面回到页首，关闭详情仍保留原列表位置。
- 多选入口及批量操作栏更加清晰，保留拖拽和按钮两种整理方式。
- 详情支持左右键翻图、独立原图查看、下载原图和 Esc 分层退出。
- 任务页提供进行中、待处理、已完成分类。
- 窄屏侧栏增加遮罩、关闭按钮、Esc 退出和焦点循环；关闭状态不进入键盘导航。

## 验证

TypeScript 检查和 Vite 构建通过。通过 CUA 在运行中的工作台验证了标签检索、3 条 Obsidian 搜索结果、视图切换、快捷搜索、详情翻图与原图查看、文件页、任务分类、多选栏、390 px 窄屏布局及侧栏键盘操作。主要正文说明与标签文字的实测对比度超过 4.5:1。登录/初始化页面通过隔离预览检查，未修改实际账号凭据或素材。

设计约定见 `design-system/shiyi/MASTER.md`。
